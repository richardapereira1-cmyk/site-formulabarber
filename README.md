# Backup estático do Formula Barber

Gerado em 23/11/2026, 13:15:35 a partir do banco atual e do build de produção.

## Conteúdo

- O HTML, CSS, JavaScript e assets do site ficam na raiz desta pasta.
- `dados/*.json` contém os registros exportados por tabela.
- `dados/csv/*.csv` contém os mesmos registros para análise em planilhas.
- `dados/schema.ts` e `dados/migrations.sql` documentam a estrutura do banco.
- `dados/export-summary.json` informa quantidades e tabelas exportadas.

## Importante

Esta pasta é uma cópia estática do front-end. Ela não substitui o servidor, a API, o login, o banco ou o armazenamento de arquivos da Manus. Para operar o sistema completo, será necessário manter o backend e o banco ativos.

Por segurança, credenciais, hashes de senha, tokens de recuperação, cookies, sessões, chaves privadas e API keys não foram exportados. Os registros não sensíveis foram preservados.
